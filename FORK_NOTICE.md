# Unofficial Plezy Android auto-update fork

This repository is a modified fork of [Plezy](https://github.com/edde746/plezy).

The fork adds and maintains Android self-update support and automated Android release builds. These modifications are unofficial and are not releases produced by the upstream Plezy project.

Modification notice: this fork was modified for Android self-update support beginning in September 2026.

Plezy and this modified version are distributed under the GNU General Public License, version 3. See [LICENSE](LICENSE).

For each binary release published by this fork, the release notes identify the exact source tag used to build that release.
